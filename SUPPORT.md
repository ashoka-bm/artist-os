# Support

Artist OS 1.0 supports the Codex distribution and environment combinations
listed in `docs/supported-environments.md`.

For reproducible bugs and documentation problems, open a GitHub issue:

`https://github.com/ashoka-bm/artist-os/issues`

Include the Artist OS version, installation mode, operating system, Python,
Bash, and Git versions, the command that failed, and its error output. Remove
private References, artist work, credentials, and local paths that you do not
want to share.

Questions about unsupported hosts, provider adapters, finished-video
generation, publishing, or automatic learning are feature discussions rather
than 1.0 support incidents.

Security vulnerabilities belong in the private process described in
`SECURITY.md`, not in a public support issue.
