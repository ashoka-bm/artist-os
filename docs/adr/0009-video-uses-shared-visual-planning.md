# Video Uses Shared Visual Planning

Status: accepted.

Artist OS will model video as a time-based extension of the shared visual planning language used by image work, not as a separate visual ontology. **Image Role** and **Storyboard Shot** are sibling realizations of a shared **Visual Unit**: images realize the unit as a still frame, while video adds sequences, scenes, duration, motion, blocking, transitions, script or audio relationships, and audio posture. Provider-specific video generation, renderers, and Remotion-style animatic tools remain downstream adapters rather than domain authority.

This keeps improvements to Symbology Direction, Style Direction, Visual Dynamics, Shot Design, shot progression, and Prompt Variant Strategy useful across both image and video, while still giving video its own scale-general **Video Medium Plan** for storyboard-ready planning.
