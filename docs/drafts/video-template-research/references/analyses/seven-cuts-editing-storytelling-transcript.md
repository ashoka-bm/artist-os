## What It Is

This transcript explains seven useful edit cuts and frames editing as intentional story feeling rather than layers, effects, or transitions.

The core question is: what does this moment need?

## Reusable Cut Functions

- **Flow cut:** carries motion direction across shots so the viewer's eye keeps moving naturally.
- **Smash cut:** breaks rhythm to create surprise, energy, humor, tension, or an emotional reset.
- **Jump cut:** skips forward in the same setup to show progress, repetition, speed, chaos, or comedic energy.
- **Action cut:** cuts during movement so attention stays on the same action and the transition feels natural.
- **Wide-medium-close pattern:** builds clarity by moving from place to action to detail or emotion.
- **Match cut:** links moments, places, times, or meanings through similar shape, subject, position, or eye line.
- **Rhythm cut:** changes cut speed to build tension, release emotion, create contrast, or avoid flat pacing.

## Artist OS Mapping

This belongs in direction notes for Video Medium Plan and storyboard/edit planning.

It should not become a Story Template. Cut choice expresses the approved story, format, and emotional movement.

## Draft Rule

Choose cuts by moment function:

- Need smooth continuity? Use flow or action cuts.
- Need surprise or reset? Use a smash cut.
- Need speed or repetition? Use jump cuts.
- Need clarity? Use wide-medium-close.
- Need symbolic connection? Use a match cut.
- Need emotional pacing? Use rhythm cuts.

## Risks

- Adding every cut type just because the list exists.
- Using cuts as decoration instead of story function.
- Creating smooth transitions when the moment needs disruption.
- Creating disruption when the audience needs clarity.
- Letting edit tricks hide a weak story, weak micro-journey, or purposeless utility sequence.
