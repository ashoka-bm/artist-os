# Research-Backed Story Template Library

Status: research draft.

These templates are candidates for Story Journey / Beat Plan use. They are not Video Medium Plan execution structures. The Video Medium Plan should translate the approved Beat Plan into scenes, shots, motion, transitions, and audio posture.

Use these when `narrative_depth = full_story`, or when a compressed `micro_journey` needs a real emotional turn.

## Starting Set

| Template | Formula | Best Use Cases | Required Emotional Turn | Hook | Payoff | Common Failure Mode |
| --- | --- | --- | --- | --- | --- | --- |
| Observation Reframe Move | I saw this -> most people think this -> it actually means this -> here is the move | Cultural essays, artist statements, thought-leadership reels, video essays | recognition -> surprise -> agency | Start with a concrete signal. | Viewer gets a better decision rule. | Generic hot take with weak evidence. |
| Contrast Sparkline | what is <-> what could be -> final call | Speeches, manifestos, launch films, fundraising videos | dissatisfaction -> longing -> commitment | Open the gap between current pain and possible future. | End with a choice or invitation. | Contrast stays abstract. |
| Problem Agitate Solve Proof | problem -> stakes -> solution -> proof/action | Ads, advocacy videos, service explainers | anxiety -> urgency -> relief or trust | Name the audience's problem before the product. | Show the solution as believable and actionable. | Manipulative pain or unsupported solution. |
| Before After Bridge | before -> after -> bridge | Testimonials, transformation videos, creator challenge arcs | dissatisfaction -> hope -> belief | Show contrast fast. | Make the bridge transferable. | Miracle claim with vague bridge. |
| Desire Funnel | attention -> interest -> desire -> action | Product films, campaign videos, social conversion stories | indifference -> wanting -> acting | Earn attention with relevance. | One next action feels obvious. | Multiple CTAs or attention without trust. |
| Human Kebab | human scene -> nut graf -> evidence/voices -> return kicker | Mini-docs, profiles, journalism-inspired issue videos | empathy -> context -> resonance | Start with a person or lived moment. | Return to the opening with larger meaning. | Anecdote fails to represent the larger claim. |
| Accordion | zoom in -> zoom out -> zoom in -> human return | Video essays, social explainers, issue docs | intimacy -> scale -> responsibility or clarity | Start with one vivid detail. | The final detail carries systemic meaning. | Scale becomes a stats dump. |
| Thesis Counterturn Synthesis | thesis/question -> evidence -> counterturn -> stronger synthesis | Criticism, history, analytical video essays | certainty -> complication -> deeper clarity | Ask a supportable question or state a claim. | Thesis evolves. | Evidence list with no real turn. |
| Inquiry Loop | engage -> explore -> explain -> elaborate -> evaluate | Educational videos, science explainers, concept demos | confusion -> discovery -> competence | Start with anomaly, question, or misconception. | Viewer can apply or test the idea. | Explanation arrives before curiosity. |
| Cold Open Reveal Ladder | charged outcome -> partial context -> reveals -> reinterpretation | Mystery explainers, incident breakdowns, trailers | urgency -> pattern recognition -> revelation | Begin at the irreversible moment. | The opening image means something new. | Confusion lasts too long. |
| Need Cost Changed Return | familiar state -> need -> threshold -> gain -> cost -> return changed | Personal journeys, creator quests, founder films, short films | longing -> risk -> cost -> changed identity | Show why staying put is impossible. | Return proves inner change. | Achievement montage with no cost. |
| Trailer Stakes Tease | world/character -> conflict -> stakes -> withheld consequence | Trailers, teasers, launch reels, music-video teasers | curiosity -> investment -> anticipation | Establish the central question fast. | Leave a compelling unresolved want. | Chronological summary or spoilers. |
| Plant Payoff Twist | plant detail -> delay -> recognition -> payoff/twist/residue | Short films, visual gags, symbolic art videos, twist shorts | noticing -> suspense -> surprise or recognition | Plant a charged detail early. | The detail returns with emotional meaning. | Cheat twist or invisible plant. |

## Placement Rules

- Store the adapted structure in the Beat Plan.
- Use `story_template_ref` in the Video Medium Plan only as a pointer to the selected or adapted story movement.
- Do not use these templates to decide provider syntax, shot count, camera settings, or platform duration.
- For `utility_sequence`, use these only when the asset package genuinely needs a story-shaped movement.

## Review Checks To Add Later

- Does the hook create an honest promise?
- Does the middle build pressure or discovery instead of listing information?
- Does the payoff answer, reverse, or transform the promise?
- Does the story serve Artist Meaning rather than generic retention advice?
- Does the Video Medium Plan preserve the key turns rather than replacing them with shot variety?
