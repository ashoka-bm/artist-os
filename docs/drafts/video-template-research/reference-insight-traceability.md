Purpose: show where the hook, storytelling, delivery, editing, and directing references landed in the current draft framework.

## Summary

The reference insights are intentionally split by authority:

- story and narrative movement goes to Story Templates or Micro-Journey Templates;
- craft direction goes to Direction Notes;
- audience-facing video grammar goes to Cultural Format Structures;
- platform-specific execution goes to Provider Export notes;
- schema fields are promoted only when repeated walkthroughs prove durable storage is needed.

## Review Rule

When adding a new reference, do not paste its framework directly into a template. First classify the insight:

1. Does it define an audience journey? Put it in Story Templates or Micro-Journey Templates.
2. Does it define craft execution? Put it in Direction Notes.
3. Does it define a recognizable video container? Put it in Cultural Format Structures.
4. Does it define platform syntax or generation constraints? Put it in Provider Export notes.
5. Does it need validation or durable querying across stages? Consider schema promotion only after repeated walkthrough evidence.
