# Draft Decision 0014: Edit Cut Vocabulary Placement

Status: accepted in draft.

Date: 2026-06-26

## Decision

Edit cut vocabulary stays as Direction Notes.

Placement:

- Beat Plan defines emotional movement.
- Video Medium Plan may name desired edit behavior when it affects rhythm, clarity, transition logic, or viewer feeling.
- Storyboard Shots can include transition or cut intent.
- Production Route or edit planning turns cut intent into actual edit decisions.

## Rationale

Cut choice expresses the approved story, format, and emotional movement. It should not define story authority.

## Consequences

- Edit cuts can guide storyboard and edit planning without becoming Story Templates.
- Provider Export should preserve cut intent when the provider can express it.
- Deterministic render/edit routes can translate cut intent into actual edit decisions.
- Review should flag decorative cuts that do not serve the moment.
