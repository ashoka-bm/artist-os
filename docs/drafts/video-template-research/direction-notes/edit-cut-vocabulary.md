# Direction Notes: Edit Cut Vocabulary

Status: research draft.

Use edit cuts to serve the moment. Do not add cuts as decoration.

## Cut Functions

| Cut | Use When The Moment Needs |
| --- | --- |
| Flow cut | smooth eye movement across shots |
| Smash cut | surprise, energy, humor, tension, or emotional reset |
| Jump cut | progress, repetition, speed, chaos, or comedic compression |
| Action cut | natural continuity through movement |
| Wide-medium-close | clarity: place, action, detail or emotion |
| Match cut | symbolic or visual connection between times, places, subjects, or ideas |
| Rhythm cut | pacing contrast, tension build, release, calm, or chaos |

## Placement In The Flow

- Beat Plan defines emotional movement.
- Video Medium Plan can name desired edit behavior when it affects format, rhythm, or viewer feeling.
- Storyboard Shots can include transition or cut intent.
- Production Route or edit planning can translate cut intent into actual edit decisions.

## Check

Ask: what does this moment need?

- Smooth flow.
- Surprise.
- Speed.
- Clarity.
- Connection.
- Rhythm shift.
- Emotional landing.

If the answer is not clear, keep the cut simple.
