# Direction Notes: Seedance 2

Status: research draft.

These notes apply after story and format decisions. They shape a Seedance 2 export, not the story template itself.

## Provider Defaults To Test

- Use 24 frames per second.
- Write the prompt in English. Do not add a Chinese prompt pass unless the artist explicitly requests a separate experimental translation.
- Keep each generated clip at 15 seconds or less.
- Use the last frame of the previous clip as the next clip's continuity reference when sequencing.
- Name the camera or capture style.
- Specify a concrete lighting style.
- Default to no subtitles and no music for raw clips unless the approved plan says otherwise.
- Add film grain when it matches the approved style.

## Scene Design Biases

- Use medium shots or closer when characters talk or interact.
- Limit the number of active subjects.
- Minimize action so the generator has fewer simultaneous obligations.
- Add simple background motion, but keep it secondary.
- Add a visual style reference image when style consistency matters.
- Keep style, identity, wardrobe, object, and location references separate.
- Keep action density low for the selected duration.
- Use one camera movement per shot.
- Vary angle and shot scale across cuts; do not sit on the same shot size for too many consecutive shots.
- Push tighter as stakes rise.
- Prefer direct facing language over advanced camera jargon when rendering the final provider prompt.
- Use reaction, reveal, sound carry, slow push-in, or a held beat when tension matters.
- Treat recurring characters, objects, props, animals, products, and vehicles as reference-prep candidates before scene export.
- Keep continuity instructions short: match the start frame, background, head/body orientation, or action order only when those details matter.

## How This Fits The Framework

These notes belong to provider export and direction. They should not become story template fields. A story template can say "reframe the audience's assumption"; the Seedance export can say "render that beat as a 12-second close interaction with one subject, 24fps, no subtitles, no music, film grain."
