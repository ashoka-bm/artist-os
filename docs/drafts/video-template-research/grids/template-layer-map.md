# Draft Video Template Layer Map

This grid separates story structure from format and provider export.

| Layer | Decides | Examples | Does Not Decide |
| --- | --- | --- | --- |
| Story template | Hook, turn, payoff, viewer journey | Five-Line Emotional Story; Misread Signal -> Reframe -> Move; Myth -> Reality -> Move; Problem -> Failed Fix -> Better Move | Camera language, provider syntax, exact clip duration |
| Direction notes | Craft and execution principles | Hook-entry patterns, on-camera connection, zoom into the moment, edit cut vocabulary, close shots for interaction, minimize action, 24fps, film grain | The narrative turn |
| Format template | Container and media shape | Talking head, b-roll, motion graphics, documentary montage, UGC, fashion, animation | The core argument or payoff |
| Provider export | Platform-specific rendering | Seedance 2 English prompt, Higgsfield prompt, OpenMontage production route | Artist Meaning or story structure |

## Narrative Depth

| Narrative Depth | Structure Required | Examples |
| --- | --- | --- |
| `full_story` | Story Template | personal story, documentary mini-arc, reframe explainer |
| `micro_journey` | Micro-Journey Template | unboxing, product reveal, UGC testimonial, fashion fit check |
| `utility_sequence` | purpose, role, constraints, success criteria | b-roll loop, title card, product spin, style test |

## Example Combination

| Story | Format | Provider Export |
| --- | --- | --- |
| Misread Signal -> Reframe -> Move | Talking head with b-roll | Seedance 2 short clips, no subtitles/music, 24fps, medium/close framing |
| Problem -> Failed Fix -> Better Move | Screen demo or hybrid source-support | OpenMontage-style production route |
| Myth -> Reality -> Move | Motion graphics explainer | Remotion/HyperFrames or Seedance b-roll inserts |
| Five-Line Emotional Story | Personal story, mini documentary, cinematic sketch | Seedance 2 scene batch or OpenMontage-style production route |
