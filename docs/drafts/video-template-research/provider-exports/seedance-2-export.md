# Provider Export: Seedance 2

Status: research draft.

## Role

Seedance 2 is a post-storyboard export target. It should receive compact scene segments, not the full story template unless the story fits inside one short clip.

## Draft Export Checklist

- Story beat selected.
- Format selected.
- Clip duration is 15 seconds or less.
- 24 frames per second included.
- Prompt body is written in English.
- No Chinese prompt text is produced unless the artist explicitly requests a separate experimental translation.
- If using the cinematic protocol, one scene/batch is rendered at a time, shot count is derived from total duration, six shots is the default cap, and reference files are listed with their provider tray bindings.
- Camera or capture style named.
- Lighting style named.
- No subtitles unless the approved plan requires them.
- Music and ambience follow the approved audio posture; do not add them by habit.
- Character interaction framed medium shot or closer.
- Active subjects limited.
- Action minimized.
- Background motion added only as secondary motion.
- Visual style reference image mapped, if used.
- Current provider reference tags confirmed, scoped, placed inline, and repeated per shot where needed.
- Audio tags, if used, are bound inline to the speaking action and do not duplicate a line already carried by the audio clip.
- Previous clip's last frame used as continuity input, if this is a sequence.
- Film grain included only when style-approved.

## Export Boundary

Do not use this checklist to invent the story. Use it to translate an approved story beat and format into a Seedance 2-ready prompt.
