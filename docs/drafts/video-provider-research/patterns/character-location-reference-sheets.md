# Draft Pattern: Character And Location Reference Sheets

Status: research draft.

Animated scene packs may need both character continuity and location continuity. A character sheet controls how the subject looks. A location sheet controls how spaces look and where characters can be placed.

## Character Sheet

Useful views:

- Full-body front.
- Full-body rear.
- Front close-up.
- Profile close-up.

The sheet should keep art style, clothing, accessories, proportions, and facial details consistent. Avoid visible text unless labels are explicitly needed for human review only.

## Cinematic Reference Set

For recurring subjects in photoreal or cinematic Seedance workflows, a single sheet may not be enough. The draft reference set can include:

- a turnaround sheet for full-body or full-object continuity;
- a dead-on identity plate for the strongest face or object anchor;
- a close-up detail sheet for skin, hair, eyes, hands, texture, surface wear, markings, or product material.

Use the turnaround in wide, full, and medium shots where silhouette, clothing, proportions, or full object shape matter. Use the identity plate when the face or primary object identity must read. Use the detail sheet in close views or medium shots where texture is visible.

## Location Sheet

Useful views:

- Four views of the same location.
- No characters in the panels.
- Consistent lighting, color, and style.
- Deliberate negative space for a subject to stand, sit, enter, or interact.

## Artist OS Mapping

Character sheets map to Visual Reference Sheet Plan. Location sheets may use the same plan type with a `setting` role until a dedicated setting-reference artifact exists.

## Risks

- Visible labels bleed into later scene generations.
- A location sheet with no negative space makes later character placement awkward.
- Character and location sheets use different styles.
- The provider treats a sheet as a collage to reproduce rather than a continuity reference.
