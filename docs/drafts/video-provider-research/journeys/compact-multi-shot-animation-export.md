# Draft Journey: Compact Multi-Shot Animation Export

Status: research draft.

## End Product

A short ready-to-paste animation provider prompt that condenses a storyboard-ready scene into a compact timecoded shot sequence.

## Likely Inputs

- Approved Video Medium Plan or storyboard-ready package.
- Character description or reference sheet.
- Scene action or script.
- Location and time of day.
- Target duration.
- Provider character limit.

## Prompt Needs

- Timecoded shot paragraphs.
- Shot size, lens shorthand, camera angle, and camera movement per shot.
- Inline dialogue.
- Location metadata.
- Audio metadata.
- Character-limit trimming.

## Known Risks

- Compression removes traceability or emotional intent.
- The prompt repeats character description instead of advancing the scene.
- Dialogue does not fit the duration.
- Consecutive shots repeat the same visual grammar.
- The export becomes a new plan instead of rendering the approved plan.

## Artist OS Mapping

This journey sits after storyboard approval. It consumes Video Medium Plan shots and outputs provider prompt text. It should store the export as a draft provider artifact linked to the source plan.
