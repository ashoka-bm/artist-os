# Draft Journey: Motion Graphics B-Roll Package

Status: research draft.

## End Product

A coherent package of motion-graphics cards, infographics, title screens, process flows, and takeaway visuals for an explainer or creator video.

## Likely Inputs

- Approved style still or design reference.
- Exact text for each graphic.
- Graphic count and roles.
- Aspect ratio.
- Palette, typography, layout, and highlight rules.
- Segment placement or timing.

## Prompt Needs

- Shared design system before per-graphic prompts.
- Exact text preservation.
- Clear layout role for each card.
- Motion rules that serve readability.
- Consistent color, type scale, grid, and callout behavior.
- Output strategy: provider prompt, rendered design system, or hybrid.

## Known Risks

- Text renders incorrectly.
- Cards drift away from the approved still.
- Motion distracts from comprehension.
- Process graphics become visually pleasing but unreadable.
- Provider output may not be editable.

## Artist OS Mapping

This journey may sit beside the Video Journey rather than inside a standard scene path. It likely needs package-level planning, exact text blocks, style calibration, and an implementation decision between provider generation and deterministic rendering.
