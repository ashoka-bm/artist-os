# Draft Journey: Style-Restyle Animation

Status: research draft.

## End Product

An animated clip where an approved character design is restyled into a specific animation language before motion.

## Likely Inputs

- Original character reference sheet.
- Target style description or style reference.
- Restyled character sheet.
- Action and setting.
- Camera movement.

## Prompt Needs

- Restyle step before animation.
- Approval or selection of the restyled sheet.
- Continuity lock for original character features.
- Style lock for the target animation language.
- Simple motion prompt using the restyled sheet as visual authority.

## Known Risks

- Style transfer changes the character too much.
- The provider preserves character but weakens the target style.
- The video prompt re-describes style inconsistently with the restyled sheet.
- Motion adds artifacts that conflict with the chosen medium, such as stop-motion or retro game movement.

## Artist OS Mapping

This journey belongs after Style Direction and before provider video export. Restyled sheets should be calibration Output Records, and the final video export should trace back to the approved style calibration.
