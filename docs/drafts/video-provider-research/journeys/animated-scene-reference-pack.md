# Draft Journey: Animated Scene Reference Pack

Status: research draft.

## End Product

A reusable reference pack for an animated scene or scene series: style build, character sheet, location sheet, still scene prompts, and compact video prompts.

## Likely Inputs

- Character concept.
- Animation style.
- Clothing and accessory details.
- Location concept.
- Scene list.
- Optional dialogue.

## Prompt Needs

- Style build prompt.
- Character sheet prompt.
- Location sheet prompt.
- Scene still prompts.
- Video prompt exports.
- Consistency rules across all assets.

## Known Risks

- The style build and character sheet diverge.
- The location sheet is not usable for staging.
- Scene stills introduce details that conflict with the character sheet.
- Later video prompts ignore approved stills.
- Too many artifacts are generated without clear approval gates.

## Artist OS Mapping

This journey likely spans Visual Reference Sheet Plan, Video Medium Plan, storyboard still policy, provider exports, and Output Records. It should remain draft until Artist OS decides how to model setting reference sheets and scene packs.
