# Structure Library

The Structure Library gives Artist OS reusable movement and format patterns without turning them into rigid templates.

It has two parts:

- **Story Structure Library**: reusable deep movement patterns selected during Story Journey and adapted inside the Beat Plan.
- **Cultural Format Structure Library**: reusable audience-facing format grammars selected during Medium Plan creation after Medium Output Shape Recommendation.

There are currently only these two Structure Library families. Other repo libraries, such as Workspace Library or visual-tension vocabulary, are separate systems and are not Structure Library families.

Library entries stay concise and operational. Research can ground an entry, but the entry itself should store the usable structure, not a citation list.

## Interaction Order

Use the libraries in this order:

1. Select or adapt a **Story Structure** during Story Journey.
2. Store the project-specific Adapted Story Structure in the Beat Plan.
3. Let the Medium Plan recommend and accept an output shape from the approved Beat Plan.
4. Select or adapt a **Cultural Format Structure** only when the medium form has recognizable audience-facing grammar.
5. Map Cultural Format Structure parts to Medium Plan sections, scenes, movements, image roles, or other medium-owned parts.

Story Structure owns movement. Medium Plan owns output shape. Cultural Format Structure owns recognizable form grammar.

## Story Structure Entry Format

Each Story Structure entry should include:

- Entry id
- Name
- Scope
- Structure grounding
- Grounding status
- Grounding tier
- Use when
- Core movement
- Typical Beat Roles
- Key turns
- Compression guidance
- Expansion guidance
- Medium affinities
- Common failure modes
- Adaptation questions

Story Structure entries guide the Beat Plan. They do not choose output shape, asset count, text form, shot count, song form, or publication format.

## Cultural Format Structure Entry Format

Each Cultural Format Structure entry should include:

- Entry id
- Name
- Scope
- Structure grounding
- Grounding status
- Grounding tier
- Use when
- Audience promise
- Audience Hook logic
- Expected parts
- Turn or payoff behavior
- Pacing norms
- Required decisions
- Common failure modes
- Adaptation questions
- Recommended Stewardship Views

Cultural Format Structure entries guide the Medium Plan. Their parts map to Medium Plan sections, scenes, movements, or other parts. They do not replace section jobs, Intended Feeling, Expectation Turn translation, voice, fidelity policy, or review requirements.

## Grounding Status

- `provisional`: useful but not researched enough to treat as stable.
- `researched`: checked against recognized structure or craft sources.
- `artist_defined`: created by the artist for a body of work.
- `project_specific`: created for one project or rehearsal.

## Grounding Tier

- `canonical_framework`: a widely recognized named structure or tradition.
- `craft_authority`: a structure taught or used by a recognized craft field.
- `platform_pattern_evidence`: a format pattern recognized through current publishing, social, or media behavior.
- `artist_defined_project_specific`: a structure defined by the artist or by one project.
