# Cultural Format Structures

Cultural Format Structure entries describe audience-facing format grammar. They help Artist OS make a Medium Plan feel culturally legible without replacing the Beat Plan or the Medium Plan's execution structure.

Read this index first, then open only the entry that matches the accepted output shape.

| Entry id | File | Use when |
| --- | --- | --- |
| `hook_driven_article` | [hook-driven-article.md](hook-driven-article.md) | An article needs a strong hook, promise, turn, and payoff. |
| `service_article_how_to` | [service-article-how-to.md](service-article-how-to.md) | The piece should help the reader understand, choose, fix, do, or improve something. |
| `feature_article` | [feature-article.md](feature-article.md) | The piece uses scene, character, evidence, and context to reveal a subject's meaning. |
| `op_ed` | [op-ed.md](op-ed.md) | The piece makes a timely, accountable public argument. |
| `short_story` | [short-story.md](short-story.md) | The piece needs a complete fictional pressure, turn, and residue within limited space. |
| `screenplay_scene` | [screenplay-scene.md](screenplay-scene.md) | The piece is a screen or script scene with objective, obstacle, turn, and early exit. |
