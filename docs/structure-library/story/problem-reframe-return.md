# Problem / Reframe / Return

**Entry id**: `problem_reframe_return`

**Scope**: A compact rhetorical or experiential movement starts with a felt problem, changes the frame of that problem, then returns the audience to action, perception, or meaning.

**Structure grounding**: Platform-era problem/reframe/payoff pattern.

**Grounding status**: `provisional`

**Grounding tier**: `platform_pattern_evidence`

**Use when**: The work needs a direct modern shape for essays, posts, service pieces, reflective articles, talks, or short videos where the main movement is not plot but changed understanding.

**Core movement**: The audience recognizes a problem or pressure. The work reveals that the first frame is incomplete, misleading, or too narrow. The ending returns the audience to the original situation with a more useful perception, choice, or practice.

**Typical Beat Roles**:

| Role | Function |
| --- | --- |
| Felt problem | Names or shows the pressure the audience can recognize. |
| Stakes | Clarifies why the problem matters now. |
| First frame | Shows the obvious or common interpretation. |
| Reframe | Changes what the problem means. |
| Return | Applies the new frame to the original pressure. |
| Residue or next move | Leaves the audience with perception, action, or a changed question. |

**Key turns**:

- Problem recognition: the audience feels addressed.
- Reframe: the work changes the governing interpretation.
- Return: the reframe proves useful in the original situation.

**Compression guidance**: In short works, make the problem concrete, reframe it once, and close with one changed noticing or action.

**Expansion guidance**: In longer works, test the first frame through examples before reframing. Use sections to show where the old frame fails, not to pile up complaints.

**Medium affinities**: Articles, essays, explainers, talks, short videos, social posts, artist statements, and instructional or reflective works.

**Common failure modes**:

- The problem is exaggerated to force attention.
- The reframe is only a synonym for the original claim.
- The return becomes advice without emotional or conceptual payoff.
- The shape drifts into generic problem-solution copy.
- The entry is treated as canonical before more research hardens it.

**Adaptation questions**:

- What problem does the audience already feel or can quickly recognize?
- What first frame will they likely bring?
- What reframe changes the pressure without dismissing it?
- What does the return let them see, do, or ask differently?
- Should the ending produce action, attention, relief, discomfort, or resolve?
